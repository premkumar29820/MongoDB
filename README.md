# MongoDB Student Management System

A beginner-friendly MongoDB project created to practice database operations and understand how MongoDB can be integrated with a full-stack application.

## Features

- Create MongoDB database and collection
- Insert single and multiple student documents
- Read and filter student records
- Update single and multiple documents
- Delete single and multiple documents
- Practice MongoDB query operators
- REST API using Express.js
- MongoDB integration using Mongoose
- React frontend

## Technologies Used
- MongoDB
- MongoDB Shell (mongosh)
- Mongoose

## MongoDB Concepts Practiced

### CRUD Operations

- `insertOne()`
- `insertMany()`
- `find()`
- `updateOne()`
- `updateMany()`
- `deleteOne()`
- `deleteMany()`

### Query Operators

- `$gt` – Greater than
- `$lt` – Less than
- `$in` – Match values from a list
- `$and` – Match multiple conditions
- `$or` – Match either condition
- `$exists` – Check whether a field exists

#Learning Outcome

This project helped me understand MongoDB fundamentals, CRUD operations, query operators, Mongoose, Express.js APIs, and React-to-backend integration.
